# Skyscrapers

Skyscrapers is a hands-on full-stack engineering study workspace. It combines structured study plans with small implementation projects so that each topic can be learned, practiced, explained, and revisited.

## How to use this repository

1. Choose a phase from the [topic roadmap](topics/README.md).
2. Read the topic README before opening the source files.
3. Open the project README inside an exercise folder to learn its purpose, concepts, and suggested practice.
4. Run or inspect the smallest example first, then change one thing and record what you learned in [Journal](Journal/learning.md).

## Roadmap

- [Java Foundations](topics/Foundations/README.md) - syntax, types, control flow, input/output, and debugging.
- [Git and GitHub](topics/02-git-and-github/README.md) - version control and collaboration habits.
- [Object-Oriented Programming](topics/03-oop/README.md) - constructors, encapsulation, inheritance, abstraction, and polymorphism.
- [Core Java Toolkit](topics/04-core-java-toolkit/README.md) - collections, streams, I/O, testing, tooling, and concurrency.
- [Spring Boot and APIs](topics/05-spring-boot-and-apis/README.md) - backend services and API design.
- [Databases](topics/06-databases/README.md) - relational modeling, SQL, persistence, and performance.
- [Frontend Foundations](topics/07-frontend-foundations/README.md) and [React](topics/08-react-development/README.md) - browser and UI engineering.
- [Third-Party Integrations](topics/09-third-party-integrations/README.md) - external services and reliability.
- [Data Structures and Algorithms](topics/10-data-structures-and-algorithms/README.md) - problem solving and complexity.
- [Career Preparation](topics/11-career-preparation/README.md) - communicating technical work.
- [ShopFlow Capstone](topics/12-capstone-shopflow/README.md) - integrating the roadmap into one product.

## Study plans

The [DevLessons study plans](DevLessons/study-plans/README.md) provide the longer reading and review schedule. The `topics` directory provides the code, exercises, and project documentation that turn that schedule into practice.
