# ShopFlow Part D: Data Structures and Algorithms

This study plan builds algorithmic problem-solving skill through data structures, complexity analysis, algorithm families, and repeated recall.

## You can learn

- How to choose a data structure for an operation.
- How to explain time and space tradeoffs.
- How to recognize patterns such as recursion, searching, sorting, and sliding windows.

Use `plan.md` for the sequence and the tracker/checklist files for daily practice.
