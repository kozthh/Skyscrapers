# ShopFlow Part B: Frontend Engineering and Audit

This study plan develops browser, JavaScript, TypeScript, React, accessibility, responsive design, and frontend review skills.

## You can learn

- How to build interfaces that work across screen sizes.
- How component structure, state, forms, and data fetching fit together.
- How to audit a frontend for usability, accessibility, and maintainability.

Use `plan.md` for the sequence and the tracker/checklist files for daily execution.
