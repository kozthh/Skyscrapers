# Search and Sorting Algorithms

This C++ collection contains small implementations of linear search, binary search, bubble sort, insertion sort, and merge sort.

## What you can learn

- How search and sorting algorithms move through data.
- Why binary search requires ordered input.
- Comparing quadratic sorts with merge sort.
- Tracing loops and estimating time complexity.

The child folders are independent exercises. Trace one implementation by hand on five values, then compare the work performed by another algorithm.
