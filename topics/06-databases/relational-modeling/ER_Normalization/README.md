# Orders: ER Modeling and Normalization

This SQL exercise designs an order-related relational schema and applies normalization ideas to reduce duplicated data.

## What you can learn

- Identifying entities, attributes, and relationships.
- Splitting repeated data into related tables.
- Primary keys, foreign keys, and functional dependencies.
- Checking whether a design approaches first, second, or third normal form.

Read `orders.sql` from top to bottom. Draw the relationships before running statements, then insert an order with multiple products and explain where each value belongs.
