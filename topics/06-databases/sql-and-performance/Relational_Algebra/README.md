# Relational Algebra Practice

This SQL exercise applies selection, projection, joins, and aggregation to a small analysis problem.

## What you can learn

- Translating relational algebra into SQL.
- Distinguishing filtering from joining.
- Predicting how duplicates and nulls affect results.
- Reading a query as a sequence of set transformations.

Read `FinalACt1.sql`, rewrite one query using another join style, and compare the result and assumptions.
