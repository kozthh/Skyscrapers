# Basic Programming Exercises

This folder gathers the first runnable exercises for input/output, declarations, loops, arrays, sorting, and small object-oriented models.

## How it is organized

- `HandsOnExcercises/Array` contains array, grade, quiz, and introductory C++ practice.
- `HandsOnExcercises/BasicLoops` contains loop-driven calculations and sorting.
- `HandsOnExcercises/Declaration` isolates Java type and declaration basics.
- `HandsOnExcercises/WrapperClasses/LibraryBooks` is the first multi-class mini-project.

Use the README in each child project to understand its goal and choose a small experiment.
