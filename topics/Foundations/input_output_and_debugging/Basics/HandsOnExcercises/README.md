# Foundations Hands-On Exercises

This collection turns introductory programming ideas into small Java and C++ exercises. Each child folder isolates a narrow skill so it can be read, run, and modified quickly.

## Projects and lessons

- `Array/CppGradeAveage` - aggregate values and calculate an average in C++.
- `Array/CppGradeCalculator` - combine input, arrays, and grade calculations.
- `Array/DSA/Syntax` - practice basic C++ syntax and declarations.
- `Array/QuizApplication` - model a small interactive Java quiz.
- `BasicLoops/GradeCalculator` - use loops and conditions for repeated calculations.
- `BasicLoops/sorting` - practice ordering values with iterative logic.
- `Declaration` - inspect Java declarations and data types.
- `WrapperClasses/LibraryBooks` - combine classes, collections, and custom exceptions.

## Suggested method

Read the smallest file first, predict its output, run it, and then change one input or rule. The useful lesson is the explanation of why the output changed.
