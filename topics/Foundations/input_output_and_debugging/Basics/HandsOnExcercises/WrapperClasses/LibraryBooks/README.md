# Library Books

This Java mini-project models books, a library, and book-related exceptions.

## What you can learn

- Object collaboration across packages or folders.
- Collections and lookup behavior.
- Custom exceptions for missing or unavailable books.
- How a main class coordinates a small domain model.

Read `Main/BookStore.java`, then trace into `Books` and `Exceptions`. Add a borrow operation that distinguishes a missing book from an unavailable book.
