# Shape Area Calculator

This Java exercise calculates areas through a common shape abstraction. It shows how a caller can work with circles, rectangles, and triangles without knowing each formula directly.

## What you can learn

- Shared contracts and polymorphic behavior.
- Separating input options from calculation classes.
- Extending a small design with another shape.
