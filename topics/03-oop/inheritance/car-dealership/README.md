# Car Dealership Hierarchy

This Java project models sedans, SUVs, and crossovers with parent classes, child classes, and an invalid-price exception.

## What you can learn

- Multi-level inheritance and specialization.
- Reusing common vehicle data.
- Domain exceptions and validation rules.
- The maintenance cost of a deep hierarchy.
